About

My name is John and I’m a musician with a bachelor’s degree in Business and Marketing, and I studied literature and languages at the Sorbonne. I’m fluent in English and French, understand Russian natively though I don’t speak it well, and I get by in Spanish. I am not an engineer by background, but I began learning software development 2 years ago, and have spent the past year working on a number of projects by directing & managing a number of Claude Code sessions that run in parallel. The source for my projects is private because I currently plan to sell the software, apps, and games. Access to the source/zip snapshots is available to reviewers upon request.

Elestruct: an all-in-one procedural authoring suite. SDF-based 3D modeling and noise authoring using graph nodes, that can be rigged, animated, and placed into a level/world editor, with export options available at each stage.
Status: Godot 4, ten milestones complete, 2,300+ tests, with an [engine purity test sample uploaded here](code-samples/test_engine_purity.gd)

Mazony: a Rust and wgpu re-authoring of two Godot procedural-graphics addons (that also served as the foundations for Elestruct) plus an audio/visual signal bridge, intended as the graphics foundation for a planned DAW where the payoff is “texture-as-oscillator”
Status: Rust and wgpu, all migration phases complete plus the studio UI


ShortCircuit: a deck-building roguelike where every hand is a real circuit on a simulated breadboard so as to function as a game that also teaches the player real electronics/circuitry
Status: Godot 4, early prototype


Robotics & Learning: A project to learn robotics & engineering with Claude's assistance, a [plan for building a hexapod](robotics/hexapod-independent-build-plan.md), along with an [OpenSCAD file](robotics/hexapod_frame.scad) generated by Claude which has been checked and corrected, in [robotics](robotics/). A [robotics core guide](learning/Robotics_Core_Guide.pdf) and [robotics formula drill book](learning/Robotics_Formula_Drill_Book.pdf) as learning materials created by Claude to follow along with and learn the fundamentals of robotics, while making the math & physics behind robotics readily available to practice.
Status: Plan stage, nothing built yet.
